# 🌿 Ana Belas Store

Site institucional e vitrine de produtos para a **Ana Belas Store** — loja de lingerie e moda íntima feminina.

## 🎨 Paleta de Cores

| Cor | Hex |
|-----|-----|
| Verde Menta | `#A8D5C2` |
| Creme | `#F7F2E7` |
| Verde Escuro | `#3D6B56` |

## 🛠️ Tecnologias

- **HTML5** — Semântico e acessível
- **Tailwind CSS v3.4** — Via CDN
- **CSS Customizado** — Animações, marquee, tema completo
- **JavaScript ES6+** — Sem dependências externas
- **Google Fonts** — Playfair Display + Poppins

## 📁 Estrutura

```
Ana_Belas/
├── index.html              # Página principal
├── assets/
│   ├── css/
│   │   └── styles.css      # Estilos customizados
│   ├── js/
│   │   └── main.js         # JavaScript principal
│   └── images/             # Imagens do site
└── README.md
```

## ✨ Funcionalidades

- Barra de anúncios com scroll infinito (marquee)
- Header sticky com efeito glassmorphism
- Menu mobile slide-in com overlay
- Hero section com imagem e CTA
- Grid de categorias com ícones SVG
- Carrossel de produtos com auto-scroll
- Sistema de favoritos com toast notifications
- Seção de benefícios
- Seção "Sobre nós"
- Newsletter com validação
- Footer completo com redes sociais
- Botão "Voltar ao topo"
- Modal de busca
- Animações de scroll (Intersection Observer)
- Lazy loading de imagens
- Design responsivo (mobile-first)

## 📱 Responsivo

O site é totalmente responsivo com breakpoints em:
- 374px (small mobile)
- 640px (mobile landscape)
- 768px (tablet)
- 1024px (desktop)
- 1280px (large desktop)
